Privacy Notice

SkillBridge AI is a student prototype for the IBM Bob Better Bengaluru Challenge. This notice explains what data is collected and how it is used.

1. What this application is

SkillBridge AI is a demonstration prototype — not a production employment platform. Job listings are fictional sample data for testing only. They are not real vacancies and are not affiliated with the named companies.

2. Data collected

  • Account data (when you register): email address, display name, hashed password, and the date you gave consent. Passwords are hashed using PBKDF2-SHA256 and never stored in plain text.
  • Application records: job titles, company names, and status notes you save in the tracker.
  • Resume files: PDF, DOCX, or TXT files you upload. These are saved in the uploads/ directory on the server running this demo.
  • Extracted skills: text parsed from your resume by keyword matching — no external service is called.
  • Session cookie: a signed, HTTP-only session cookie is set on login. It contains your user ID only, not personal data.

3. How resume files are processed

Resume text is extracted locally on the server using open-source Python libraries (pypdf and python-docx). Skills are identified by keyword matching against a fixed vocabulary list.

If IBM watsonx.ai credentials are configured, resume text may be split into chunks and embedded using the ibm/granite-embedding-278m-multilingual model to enable context-aware career guidance. Embeddings are stored in the local SQLite database and are never sent to any third party other than IBM watsonx.ai when the feature is enabled.

Do not upload resumes containing sensitive personal information (national ID numbers, bank details, medical history) to this demo deployment.

4. AI processing

When IBM watsonx.ai credentials are configured, career guidance questions may be sent to the ibm/granite-4-h-small foundation model hosted on IBM Cloud. Without credentials, all responses come from the built-in rule-based system — no external API is called.

The assistant never claims qualifications, salaries, or job offers on your behalf. All AI-generated text is advisory only.

5. Data storage and retention

All data (accounts, applications, resume chunks) is stored in a local SQLite database file (database.db) on the server running this demo. No data is sent to external databases or analytics services.

This is a demonstration prototype — there is no automated data retention or deletion policy. Treat this application as a local development tool.

6. Cookies and browser storage

  • Session cookie: set on login, cleared on logout. Contains only a signed user ID.
  • Language preference (sb_lang): stored in localStorage to remember your EN/KN choice. No personal data.
  • Consent acknowledgement (sb_consent): stored in localStorage to suppress the consent banner after the first visit.
  • No tracking cookies, advertising cookies, or third-party analytics are used.

7. How to delete your data

Since this is a local demo, you or the system administrator can delete all data by removing the database.db file and the uploads/ directory. There is no in-app account deletion UI in this prototype version.

8. Contact

This application was built as a student project for the IBM Bob Better Bengaluru Challenge. For questions about this prototype, raise an issue on the project's GitHub repository.
